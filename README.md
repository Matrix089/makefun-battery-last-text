A tiny Python program that writes the phone battery's last text to its charger, one line, to /output/entry.txt for make.fun's The Battery's Last Text to Its Charger bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
